# Antigravity & AI Agent Skills Directory

This folder is designed to store skills for AI coding agents.

## Folder Structure

Place each downloaded skill into its own subfolder containing a `SKILL.md` file:

```
.agents/skills/
├── turnstile-spin/
│   └── SKILL.md
├── my-skill/
│   ├── SKILL.md
│   ├── scripts/
│   └── references/
```

## SKILL.md Format Example

```markdown
---
name: my-skill
description: Brief description of what this skill does and when to activate it.
---

# Instructions
Detailed steps and workflow for the AI agent to follow.
```
